# A09: Security Logging and Monitoring Failures - Starter Lab

## Goal
Verify whether attacks are logged, alertable, and actionable.

## Scenario
Security-relevant events are missing, noisy, or unmonitored.

## Steps
1. Trigger auth failures, access denials, and suspicious inputs.
2. Check logs for event quality (who/what/when/source/result).
3. Verify alert path for high-risk activity.
4. Improve logging schema and alert rules.

## Evidence
- Missing key events
- No alert despite attack behavior

## Remediation
- Structured security logging standard
- Centralized retention + alerting
- Detection playbooks for responders
