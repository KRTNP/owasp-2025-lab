# CTF Track (HTB-style)

This folder contains standalone CTF challenges with storyline, flags, and intended exploit chains.

## Difficulty Model
- `easy`: single-issue, direct exploit
- `medium`: 2-step chain
- `hard`: 3+ step chain, misleading noise, partial dead-ends

## Rules
- Local authorized environment only
- No attacks outside your own lab infra
- Keep challenge artifacts private when actively solving
