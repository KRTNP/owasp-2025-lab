# Flag Specification

- Flag format: `FLAG{...}`
- Flags are stored server-side in challenge-specific locations.
- Each solved stage unlocks hints for the next stage.

## Suggested Placement
- Stage 1 flag: user profile metadata
- Stage 2 flag: unauthorized tenant invoice record
- Stage 3 flag: internal service diagnostic endpoint
- Final flag: admin-only vault endpoint reachable after pivot
